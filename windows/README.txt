hyprclick for Windows
=====================

Unzip the whole folder somewhere and run hyprclick.exe. Keep the files
together: WinDivert.dll and WinDivert64.sys are what the Lag tab uses.

Keys (change them in the app):
  ALT+H  start / stop clicking
  ALT+Z  lag: timed freeze
  ALT+X  lag: freeze on / off
  ALT+C  lag: freeze while held
  ALT+B  fake lag on / off

The keys work while hyprclick is open, minimized is fine.

Clicker: use Cursor mode. Target is RobloxPlayerBeta.exe by default.
Anti-AFK: Window switches to Roblox for a moment every few minutes, wiggles
the mouse, and switches back. It skips that if you're playing.

Lag tab: right-click hyprclick.exe > Run as administrator (or press the
button in the tab). Windows only lets administrators hold back or drop
network packets. Pick Roblox under One app, or use Whole PC.

Windows SmartScreen may warn about an unknown app the first time, since
it isn't signed: More info > Run anyway.

Using lag tools in online games can break their rules and get your
account banned.
